## Задача

Зараз обробка заявок на перевезення виконується вручну: оператор копіює дані
з пошти в таблицю, далі заводить запис у CRM і повідомляє водія в месенджері.

Треба автоматизувати наскрізний ланцюжок:

```
заявка → валідація → запис у CRM → сповіщення водія
```

**Обсяг:** ~400 заявок на тиждень. Пікові дні — понеділок і четвер
(це важливо для розрахунку лімітів API й черги повторних спроб).

## Критерії приймання

1. Заявка з некоректним телефоном **або** без адреси доставки не потрапляє в CRM.
2. Сповіщення водію йде не пізніше ніж через **2 хвилини** після надходження заявки.
3. Усі відхилені заявки видно в окремому звіті.
